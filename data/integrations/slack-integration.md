# Connect TaskFlow to Slack

The Slack integration can send TaskFlow activity notifications to Slack channels.

## Connect Slack

1. Open **Workspace settings**.
2. Select **Integrations**.
3. Choose **Slack**.
4. Select **Connect**.
5. Authorize TaskFlow in Slack.
6. Choose the channels that should receive notifications.

You must have the required Slack permissions to install the integration.

Workspace administrators can disconnect Slack from TaskFlow at any time.
