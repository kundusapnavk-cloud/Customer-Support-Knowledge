# GitHub Integration

The GitHub integration connects TaskFlow projects with GitHub repositories.

## Connect GitHub

1. Open **Workspace settings**.
2. Select **Integrations**.
3. Choose **GitHub**.
4. Authorize TaskFlow.
5. Select the repositories you want to connect.

Connected repositories can be associated with TaskFlow projects.

Repository access depends on the permissions granted to the TaskFlow GitHub application.
