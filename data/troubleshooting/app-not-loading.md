# TaskFlow App Is Not Loading

If TaskFlow does not load correctly, try the following steps.

## Web

Refresh the page, disable browser extensions temporarily, and clear TaskFlow site data.

## Mobile

Force close the app and reopen it. Confirm that you are running a supported version of the TaskFlow application.

## Network

Corporate networks, VPNs, or firewalls may block required TaskFlow connections.

If the issue affects multiple users, contact TaskFlow Support with the device, operating system, and error details.
